Trace tool: mockup for 0025 (UX proposal of 2026-10-14)

Static sketch at 1:1 for an 800 x 600 window. Not a build reference: ux-proposal.md holds the numbers. The image is a stand-in for a picture; the blue outline is the preview, the document is unchanged. The right panel has no Trace section.

1. Trace tool active, image selected, preview running

2. States of the bar

3. Comparing trace and original

The View pill in row 1 has three icon segments with tooltips: Overlay (dimmed image plus outline, default), Trace (the result with its fills, image hidden), Image (original). Holding \ shows the original while the key is down; Shift+\ cycles the views. No split view in the first slice.

4. After Create paths

One group "Trace of cat.png" sits directly above the image in the same layer, the image is hidden, the tool is back to Select with the group selected, and the rail shows the notice "Traced: 7 paths, 412 nodes. Source image hidden." for 3 s. One undo step "Trace image" reverses both.
