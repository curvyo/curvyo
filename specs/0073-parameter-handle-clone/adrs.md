# ADRs for 0073 parameter-handle-clone

- `0015` (document model): a copy is an ordinary object made by the Duplicate path; no new node or register, no format change.
- The Ctrl modifier on the parameter handle collides with the Ctrl angle snap of `specs/0021-ellipse-arcs-and-shaping/` (criterion 56); the architect resolves this when the story is sharpened (draft: the snap stays on Ctrl, the copy moves to Alt, or both are read live).
