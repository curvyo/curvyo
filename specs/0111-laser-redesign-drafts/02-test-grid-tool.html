02 · Test grid tool

Test grid is a tool, the third button of the card that holds Offset and Measure (dashed = new). Its settings live in the tool's own bar at the top, which replaces the Select bar like the Trace bar does. A press on a laser page places a grid with the bar's values; the bar then edits the selected grid live (one undo step per commit). The grid stays one object; it resolves into ordinary operations (screen 03). Plain single sliders for Min and Max, the exact value in the field next to each, units inside the fields.
