## 1. Library page placed live into a slot (spec 0154 slice 2, PR #498)

Setup: a laser page with a holder that has two or more slots (a fixture set), a drawing page in the open document, a library with a multi-object page.

- [ ] Drag a whole library page onto an empty slot without a key: it lands as a copy, fitted (slice 1 behaviour unchanged).
- [ ] Same drag with **Ctrl** held: badge reads "Placed page into Slot 2 · 50 %" (scale varies), release places a live placed page, centred and fitted.
- [ ] Press and release Ctrl during the drag: the badge changes live.
- [ ] **Alt + Ctrl**: real size, centred.
- [ ] A page whose box fits turned (40 x 60 into 60 x 40): turned, not scaled.
- [ ] Holder rotated on the bed: the placed page turns with it.
- [ ] Into slot… list: **Placed page** toggle appears for whole pages only, not for picked elements or icons.
- [ ] Undo after a placement from a library page of another document: one step, the placement and the added page both gone ("Place page into slot").
- [ ] Drop onto a filled slot: "Slot 2 is filled.", nothing written; Replace swaps the placement and keeps the source page.
- [ ] Pages panel: **Ctrl + drag** of a drawing-page row onto a slot places that page live, no page added. Without Ctrl: old behaviour.
- [ ] Layers shows " · Slot 2", Fixtures shows the slot as filled.
- [ ] Decide: is the undo name "Place page into slot" right?

## 2. Access token for private Git catalogues (spec 0156 library-git-token, PR #501)

Needs the desktop app and a **private** GitHub repository with a catalogue (`curvyo-catalogue.json`) and a fine-grained read-only token.

- [ ] Library browser, Add source, Git catalogue: an **Access token** field (masked) is there; with Iconify it is gone.
- [ ] Add the private repo without a token: "No Git catalogue at this address." plus "For a private repository, add an access token."
- [ ] Add it with the token: source appears with a lock mark, items load.
- [ ] The token is not visible anywhere afterwards (field empty when reopened; inspect the field in dev tools: no `value` attribute with the text).
- [ ] The webview does not offer to save the password.
- [ ] `online-sources.toml` contains `token = true` and no token text.
- [ ] **Change token** with a wrong token: "The token was refused.", old state kept. With the right token: works.
- [ ] **Remove token**: lock mark gone, source then fails as without token.
- [ ] **Remove** source: the key store entry is gone (Linux: `secret-tool search` or Seahorse, service `curvyo/<slot>`, account `git-token:<address>`).
- [ ] Key store not running (stop the Secret Service): Add with a token says so and adds nothing.
- [ ] Hosting guide shows the "Private repositories" step in the desktop build.
- [ ] Known gap: Right-arrow keyboard route to the token action is not built.
